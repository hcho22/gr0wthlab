# A/B hook pairs (synthetic fixture)

Synthetic test data for gr0wthlab's package-review example set; it is not any Product's package.

Between the legs of a pair only the hook differs: the opening words on screen and the caption's first line.
Leg A of each pair opens on its Angle's Hook in the Angle bank, word for word; leg B is the Hook tested against it.
