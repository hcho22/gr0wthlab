# How to read the results (synthetic fixture)

Synthetic test data for gr0wthlab's Weekly Read checks; it is not any Product's package.

## What is noise at this sample size

- Any post under 200 impressions is unread, not failed; the floor counts each platform's views.
- A pair resolves only when both legs were readable and the rank gap is large; otherwise it reposts.
- Kills need two consecutive weekly reads at or under the criterion.
