# Weekly Reads

The Weekly Read memo for each read week, judging every live Angle against the signal registered for it in Mandu.
The agent writes it here as `window-<n>-read-<07|14>.md`, in the format its task definition gives (US-ME12); the launcher checks it and, when it passes, keeps the memo the Founder reads in `ledger/weekly-reads/` and queues one decision item for each of its lines.
A memo that fails a check stays here as written, and nothing is queued from it.
