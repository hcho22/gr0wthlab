# Evidence

What the Marketing Engineer has gathered or observed, each with its source and the date gathered: Listening quotes, post results, and the Founder's rejection reasons.
Evidence never holds an email address, and it can support a package-change proposal but never changes the Go-To-Market Package by itself.
Formats: US-ME11, US-ME13, US-ME16.

The launcher's own Evidence (each run's package snapshot, the Founder's decisions, the sittings taken in from Mandu, the Waitlist counts, and, once a Beta Build is approved, the invitation batches by entry identifier and the counts the Founder reports) is in [`ledger/evidence/`](../../ledger/README.md), which the agent can read and never write.
