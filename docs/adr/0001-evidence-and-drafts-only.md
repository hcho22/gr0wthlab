# The Marketing Engineer holds only Evidence and Drafts

The Marketing Engineer's repository holds Evidence, Drafts, and Review Queue items, and deliberately holds no positioning, Fit, claims, or other marketing strategy.
Each Product's Go-To-Market Package stays in Mandu as the single copy, because Mandu already tracks the Products and is where the Founder reviews and decides; the Marketing Engineer proposes changes through the Review Queue and Mandu applies the approved ones.
The Marketing Engineer reads Product repositories but never changes them, and hands any Product change to firstmate as a Dispatch so each Product keeps one writer and its normal reviewed path.
Every public act stays with the Founder: the Marketing Engineer only produces Drafts, and posting, sending, or confirming a publishing schedule is the Founder's.

Since 2026-10-12 the Founder no longer reviews and decides in Mandu: [ADR 0002](0002-the-founder-decides-in-gr0wthlab.md) moved the Founder's decisions into this repository, onto a local page, and made Mandu a reader.
Everything else here stands, and above all that each Go-To-Market Package stays in Mandu as its single copy.

## Considered Options

- Moving each Go-To-Market Package into this repository with an evidence tier and a decided tier was rejected so that Mandu remains the Founder's single record.
- Letting the Marketing Engineer open its own pull requests in Product repositories was rejected because two independent agents would write the same repositories outside each Product's checks.
